# Matronix

**Настоящие текстуры Minecraft → ваши изменения → готовый ресурс-пак.**

Настольный пиксельный редактор для Windows 10/11 на Python / PySide6. Поддерживает выбор **51 релизной версии Minecraft Java от 1.12.2 до 26.2 включительно**. Не поддерживает Bedrock, снапшоты и модифицированные версии.

## Готовый EXE

Workflow **Test and build Windows** собирает один портативный `Matronix.exe`. Во вкладке GitHub **Actions** откройте успешный запуск и скачайте артефакт **Matronix-Windows**. Распакуйте ZIP и запустите EXE — Python устанавливать не нужно. Цифровой подписи нет, поэтому Windows может показать предупреждение SmartScreen. Это не установщик.

Сборка из исходников на Windows:

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt pyinstaller
.venv\Scripts\python -m PyInstaller --noconfirm --windowed --onefile --add-data "matronix/versions.json;matronix" --name Matronix run.pyw
```

Результат — `dist/Matronix.exe`.

## Как перерисовать настоящие текстуры

1. Выберите точную версию Minecraft Java в верхней панели.
2. Нажмите **Загрузить оригиналы Mojang**. После подтверждения программа скачает клиентский JAR с официальных серверов Mojang, проверит размер и SHA-1 по официальному манифесту и сохранит в локальном кэше. Загрузка может занимать несколько сотен МБ, её ход отображается внизу окна. Сам Minecraft не запускается.
3. Либо нажмите **Открыть Minecraft JAR…** и выберите клиентский файл уже установленной игры, например `%APPDATA%\.minecraft\versions\1.12.2\1.12.2.jar`. Интернет для этого не нужен. Если в JAR есть `version.json`, программа проверит точное совпадение версии. У старых JAR такого файла нет: соответствие выбранной версии нужно проверить самостоятельно.
4. В каталоге появятся доступные текстуры блоков и предметов с миниатюрами. Выберите текстуру — оригинал сразу откроется на холсте. Его можно перерисовывать, не начиная с пустого изображения.
5. Сохраните проект `.matronix` и нажмите **Собрать ZIP**.
6. В выбранной версии Minecraft откройте **Настройки → Наборы ресурсов → Открыть папку**, скопируйте туда ZIP и включите пак.

Оригиналы не включены в EXE и не хранятся в репозитории. Полная загрузка клиента выполняется только по запросу пользователя через официальный манифест Mojang и URL клиента из него; отдельная онлайн-библиотека использует зеркала GitHub (см. ниже). Учётные данные не нужны. Наличие кнопки загрузки не гарантирует доступность серверов в любой сети; предусмотрен локальный JAR.

Кэш скачанных клиентов Windows: `%LOCALAPPDATA%/Matronix/Matronix/clients` (расположение определяет Qt). Его можно удалить при закрытой программе, чтобы освободить место. Оригиналы из кэша подключаются автоматически при открытии соответствующей версии. Локально выбранный JAR при следующем запуске при необходимости выберите заново.

## Версии и формат пака

Каждый проект предназначен для **одной точной версии**. Смена версии создаёт новый проект с подтверждением сохранения изменений, а не конвертирует текстуры. Пути старой версии 1.12.2 (`textures/blocks`, `textures/items`) сохраняются без переименования; в новых версиях используются реальные пути из их JAR.

Для старых версий генерируется `pack_format`; для новых с форматом 65+ — `min_format`/`max_format` с major/minor. Например, 1.12.2 использует формат 3, 1.20.4 — 22, 26.2 — 88.0. Таблица `matronix/versions.json` содержит релизы до 26.2 и основана на [истории версий mcmeta](https://github.com/misode/mcmeta/tree/summary/versions); для 1.12.2/1.13.x добавлены исторические форматы 3/4. Проверки формирования ZIP есть для всех 51 версий; это не означает, что все паки вручную проверены в игре.

## Редактор

- Карандаш с непрерывными линиями, ластик, заливка, пипетка.
- Выбор RGBA-цвета, палитра, прозрачность, отключаемая сетка.
- Отмена и повтор до 60 действий для текущей текстуры. При переключении история очищается.
- Статические квадратные PNG 16×16, 32×32 и 64×64, изменение размера без сглаживания.
- Импорт/экспорт PNG, плоский предпросмотр без сетки.
- Поиск по Minecraft ID; русские названия для стартового набора, остальные — по имени файла.
- Фильтр блоков/предметов, отметка изменённых текстур, удаление замены из пака.
- Сохранение проектов, предупреждение о несохранённых изменениях.

Только отредактированные/импортированные текстуры включаются в проект и ZIP; простой просмотр оригинала ничего не добавляет. Неизменённые ресурсы игра берёт из стандартного или нижележащего пака. ZIP и проект — разные файлы; экспорт не заменяет сохранение проекта.

Без подключённых оригиналов доступен стартовый набор на прозрачном холсте. Прозрачность в отредактированной текстуре не означает «показать оригинал». Её обработка зависит от типа блока. Некоторые текстуры (например, верх травы) дополнительно окрашиваются игрой.

### Ограничения

Анимированные вертикальные полосы, прямоугольные атласы и размеры вне 16/32/64 пропускаются; их число показывается рядом с источником. Редактирования моделей, звуков, шейдеров, сущностей и интерфейсов пока нет. Поддерживаются только текстуры блоков и предметов, не полный набор ресурсов игры. Нет 3D-предпросмотра и автоматической установки в лаунчер. Пак не меняет механику предметов и не добавляет новые блоки.

## Запуск исходников

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m matronix
```

Без консоли: `.venv\Scripts\pythonw run.pyw`.

Linux/macOS: `python3 -m venv .venv`, `.venv/bin/python -m pip install -r requirements.txt`, `.venv/bin/python -m matronix`. Нужны системные графические библиотеки Qt. Целевая сборка и CI — Windows.

**Клавиши:** Ctrl+N — новый проект; Ctrl+O — открыть; Ctrl+S — сохранить; Ctrl+Z — отменить; Ctrl+Shift+Z — повторить.

## Проверки

```sh
python -m unittest discover -s tests -v
```

Тесты ядра не требуют Qt. Проверяются проекты, ZIP всех поддерживаемых версий, оригиналы из тестового JAR, старые пути, проверка версии, защита путей, загрузка с проверкой SHA-1 и удаление неполной загрузки. GUI smoke test проверяет рисование, отмену, переключение текстур, сохранение/экспорт и редактирование оригинала; локально он пропускается без Qt/системных библиотек. Windows CI требует наличие Qt и проверяет запуск собранного EXE.

Matronix — независимый проект, не официальный продукт Mojang или Microsoft. Используйте ресурсы в соответствии с применимыми условиями Minecraft; программа не даёт дополнительных прав на их распространение.

## Версия 0.2: установщик, онлайн-библиотека и новый интерфейс

В успешной сборке Actions теперь два файла:

- **Matronix-Installer** — архив с `MatronixSetup.exe`: мастер установки на русском/английском, выбор папки, ярлык в меню «Пуск», необязательный ярлык на рабочем столе и деинсталлятор. Ставится для текущего пользователя без прав администратора. По умолчанию `%LOCALAPPDATA%\Programs\Matronix`. Удаление программы не удаляет ваши проекты и кэш.
- **Matronix-Windows** — архив с переносимым `Matronix.exe`, без установки.

Новый интерфейс: отдельная карточка проекта с версией Minecraft, библиотека слева, редактор с ID текстуры в центре, цвет и предпросмотр справа. Главная кнопка экспорта отделена от сохранения проекта. Минимальное окно — 1080×740 (Qt может увеличить его под системный масштаб/шрифт).

### Скачать только выбранные текстуры

Нажмите **«Выбрать текстуры онлайн»**, дождитесь каталога, найдите PNG по ID или русскому названию стартового набора, выберите блоки/предметы и отметьте нужные строки галочками. Кнопка «Отметить видимые» учитывает фильтр и ограничение **256 текстур за одну загрузку**. «Снять отметки» очищает весь выбор, включая скрытые строки.

Загружаются только выбранные PNG, не клиент Minecraft. Каждый файл сверяется по размеру и Git blob SHA-1 из каталога. Анимации и нестандартные размеры пропускаются. Предыдущие скачанные текстуры этой версии остаются в кэше, изменения проекта не перезаписываются оригиналами. Отмена или ошибка не заменяет предыдущий кэш. Нажатие «Закрыть» во время загрузки запрашивает отмену и ждёт завершения текущего сетевого запроса.

Онлайн-каталог использует **сторонние зеркала**, не официальный API Mojang: [mcmeta](https://github.com/misode/mcmeta) для версий 1.14–26.2 и [minecraft-assets](https://github.com/InventivetalentDev/minecraft-assets) для 1.12.2–1.13.2. Список файлов получается через GitHub API, PNG — через GitHub raw (с перенаправлением на raw.githubusercontent.com). Возможны ограничения сети и лимиты GitHub API. Если каталог недоступен, используйте локальный JAR или прежнюю загрузку целого клиента с Mojang. Учётные данные GitHub приложение не запрашивает.

Скачанные PNG хранятся локально в `clients/<версия>-selected.jar` (это только кэш выбранных ресурсов, не запускаемый клиент). При следующем запуске этот кэш имеет приоритет над полным JAR. Чтобы снова показать все оригиналы, откройте полный JAR вручную.

Для локальной сборки установщика после PyInstaller установите **Inno Setup 6** и выполните:

```powershell
& "${env:ProgramFiles(x86)}\Inno Setup 6\ISCC.exe" packaging/Matronix.iss
```

При сборке EXE используйте также `--icon matronix/icon.ico --add-data "matronix/icon.png;matronix"`. CI проверяет загрузку одной настоящей текстуры для 1.12.2 и 26.2, запуск EXE, тихую установку, запуск установленной программы и удаление. Это не замена ручной проверке каждого шага мастера.
